# Dax_-_Data_Visualisation_Assignment.PBI
Power Bi Assignment 2.
Project Overview:This Project analyzes E-Commerce sales data using PowerBi.The goal is to understand sales performance,profit,order trends and target achievement.
Tools used:Power Bi desktop,Power Query and DAX.
Key Insights:Best performing product categories,Most profitable sub categories,Monthly sales trends,Sales target achievement,regional sales performance and order distribution by state.
Objective:To gain meaningful business insights and improve sales performance through interactive Power BI visualisations.
